# AX7010 HDMI Test Pattern Demo

A minimal Vivado project that drives an 8-colour bar test pattern out of the
AX7010's HDMI connector at 1280x720@60. Use this to confirm Vivado, the JTAG
connection, and the board's HDMI-out path all work before building anything
more ambitious on top of it.

## Board / part

- Board: ALINX AX7010 (Zynq-7000, XC7Z010)
- Vivado part: `xc7z010clg400-1`
- 50 MHz onboard oscillator on pin `U18`

## Video path

```
sys_clk (50 MHz)
  -> clk_wiz_video (Clocking Wizard IP)
       -> pixel_clk  74.25 MHz
       -> serial_clk 371.25 MHz (5x pixel_clk)
  -> color_bar   8-bar colour test pattern generator + video timing
  -> hdmi_tx     per channel: tmds_encoder (DVI 8b/10b) -> oserdes_tmds (OSERDESE2 serializer) -> HDMI connector
```

The whole design is plain Verilog (`hdl/*.v`, pure RTL + Xilinx UNISIM
primitives) - no VHDL, no third-party packaged IP beyond Vivado's own
Clocking Wizard.

`color_bar` is configured for 1280x720 via `hdl/video_define.v`
(`` `VIDEO_1280_720 ``); other resolutions it supports (640x480, 800x600,
1024x768, 1920x1080, ...) can be selected by editing that file, as long as
the pixel clock generated by `clk_wiz_video` in `top.v` /
`scripts/create_project.tcl` is updated to match.

## Building the project

From a terminal, with Vivado on your `PATH`:

```sh
cd demo_test_pattern
vivado -mode batch -source scripts/create_project.tcl
```

This creates a Vivado project under `demo_test_pattern/vivado_project/`
(git-ignored) with all sources, constraints, and the clocking IP added. It
does not run synthesis. Open the generated project in the Vivado GUI, then:

1. Run Synthesis
2. Run Implementation
3. Generate Bitstream
4. Open Hardware Manager, connect to the board (JTAG), and program the device

An HDMI monitor/TV connected to the AX7010's HDMI-out should show vertical
white / yellow / cyan / green / magenta / red / blue / black bars.

## Source attribution

- `hdl/color_bar.v` and the HDMI pin assignments in
  `constraints/ax7010_test_pattern.xdc` are taken from ALINX's official
  AX7010 course examples (`course_s1_fpga/13_hdmi_out`,
  https://github.com/alinxalinx/AX7010_2023.1).
- `hdl/tmds_encoder.v` and `hdl/oserdes_tmds.v` are original Verilog ports of
  the DVI 1.0 TMDS 8b/10b encoding algorithm and the OSERDESE2 10:1 DDR
  cascade wiring used by Digilent's open-source `rgb2dvi` core (BSD
  3-clause, (c) 2014 Digilent Incorporated) - same algorithm/pin mapping,
  reimplemented in Verilog instead of VHDL.
- `hdl/hdmi_tx.v`, `hdl/top.v`, and `scripts/create_project.tcl` are written
  for this repo; the clocking-wizard MMCM settings in the latter reproduce
  ALINX's verified configuration for this exact board/part.

## Next steps

Once the test pattern is confirmed working, this project is a reasonable
starting point for a game's video output: swap `color_bar` for a framebuffer
or sprite-compositing pipeline that still produces `hs`/`vs`/`de`/RGB signals
on `pixel_clk`, and reuse `hdmi_tx` unchanged.
